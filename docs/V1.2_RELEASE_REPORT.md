# Aether LMS v1.2.0 — Gradebook and Roster

Implemented on `feature/v1.2`, continuing the existing extension. The supplied v0.8.1 baseline and all previous releases remain recoverable through tags and preserved release archives. Upgrade by copying the release contents into the existing unpacked extension folder, clicking Reload in chrome://extensions and refreshing LMS tabs. Version: 1.2.0. No settings migration or new permissions are needed.

## Result

Gradebook and Roster use the same graphite panels, mint/cyan accents, typefaces, accessible focus treatment and record cards as Resources and Assignments. The new academic stylesheet is scoped to these tools, including supported same-origin tool frames.

Student Gradebook item summaries become record cards. Native scores, weights, feedback, due dates, category headers and unpublished states are preserved exactly; no grade is calculated or inferred. Category collapse and statistics controls retain their original handlers. Editable grading grids, comparison tables and unknown grade structures retain native table layout with matching colors. Changes between read-only and editing modes restore the previous presentation attributes before applying the new mode.

Native Roster card, photo and table views receive matching presentation. Original photos and photo web components, profile links, permitted email fields, group selectors, search, sorting and pagination remain in place. Photo-only views do not gain email or other hidden data. Cards containing selectors do not tilt. Native elements and handlers are retained; OFF restores the original classes and semantics while keeping user-entered values.

## Verification

The actual unpacked MV3 extension was tested in isolated Chromium 149.0.7827.55 on Windows. Synthetic Sakai responses were intercepted before university requests could reach the network. No account, real roster, grade or academic submission was accessed.

| Suite | Result | Evidence |
|---|---:|---|
| Main browser regressions | 54/54 | `reports/v1.2.0/results.json` |
| Delayed-page startup | 5/5 | `reports/startup-v1.2.0/results.json` |
| Graphics and cancellation fallbacks | 5/5 | `reports/fallbacks-v1.2.0/results.json` |
| Final installable package smoke | 10/10 | `reports/package-v1.2.0/results.json` |
| Unit and security checks | 8/8 | `node tests/unit.cjs` |

The 18 new main browser checks cover published grade records, unreleased states, native editing and comparison tables, read/edit/read transitions, Roster photos and controls, asynchronous records, same-origin frames and OFF restoration. Gradebook and Roster screenshots and overflow checks cover 360, 390, 640, 775, 1024, 1280, 1440 and 1920 px widths. Existing resource previews, assignment forms, PDF navigation, native actions, reduced motion, stars, origin isolation and storage regressions also pass.

Fast startup remains intact: with a tool script delaying parsing by 3 seconds, stars and the first folded-field frame appeared at 268.3 ms; the full renderer drew at 679.7 ms, before DOMContentLoaded at 3100.5 ms. These are fixture observations, not live server guarantees. A separate 1440 px active-graphics sample recorded median/p95 frame intervals of 16.7/16.8 ms over 87 frames; raw conditions are in `reports/v1.2.0/performance.json`.

The final package contains 234 local assets. `release-v1.2.0-sha256.json` records archive and per-asset hashes; `reports/package-integrity-v1.2.0.json` compares the ZIP and unpacked release against normalized source assets. Tests, reports, development dependencies and Git metadata are excluded from the installable ZIP.

## Limits

Authenticated live LUMS compatibility remains unverified. Fixture coverage cannot establish every customized Sakai view, server policy or permission state. Unknown tables retain native geometry. Native hidden-tab behavior remains an automation-host limitation documented in earlier reports; it is not counted as a passing check.

The extension still requests only `storage`, uses the same LMS host restriction and packages all executable assets and fonts locally. No publication, external academic-content transfer, analytics or credential collection was added.
