# Aether LMS v1.1.0

Restores the page-wide stars and glowing sparkles requested after v1.0. Work is on `feature/v1.1`; tags `v1.0.0` and `v0.8.1` remain recoverable. Install by copying the release contents into the existing unpacked extension folder, clicking Reload in chrome://extensions, and refreshing LMS tabs. Keep the same folder to retain preferences.

## Change

The legacy `.portal-main-container` gradient was opaque, hiding the negative-layer ambient field. v1.1 clears that wrapper background while retaining opaque native panels, cards and forms. It does not position or transform native ancestors or place a blocking overlay above content.

The viewport now has a denser adaptive starfield, cached mint/cyan halos, gentle twinkling and four-point sparkles. Pointer proximity increases star brightness and glow with inertia. Motion OFF or system reduced motion keeps the field static; Aether OFF removes it. The fixed canvas follows the visible viewport as the user scrolls. Particle budgets range from 60–120 on low-power/coarse-pointer devices and 140–360 on standard devices, scaled by viewport area. The existing scheduler, DPR caps, course sculpture and LMS functionality remain intact. No new permission, dependency or network access was added.
