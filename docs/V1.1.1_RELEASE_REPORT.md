# Aether LMS v1.1.1 — faster visual startup

Implemented on `feature/v1.1.1`; releases v1.1.0, v1.0.0 and v0.8.1 remain recoverable. Upgrade by copying all release files into the existing unpacked extension folder, choosing Reload in chrome://extensions, then refreshing LMS tabs. No settings migration or permission change is required.

## Fix

Previously graphics initialization refused to run while the document was parsing and then used an idle callback with a 500 ms timeout. Slow Sakai scripts could therefore leave the hero and background undecorated for seconds.

The starfield now draws as soon as the workspace exists. A lightweight 720-point frame of the existing procedural folded geometry appears in the same layout immediately. Two animation frames let that composition paint before full WebGL initialization; the temporary canvas is removed after the actual renderer draws. This is a progressive first frame, not a loading veil or a change to LMS content. Native content never waits for shader initialization.

Pending initialization is cancelled on OFF, navigation and teardown. ON restarts cleanly. Existing reduced-motion and non-WebGL fallbacks remain in effect. The original course links, controls, previews, status parsing, preferences, fonts, permissions and domain restrictions are retained.

## Measured startup

An actual unpacked extension was tested in isolated Chromium 149.0.7827.55, with the same synthetic Sakai fixture for both releases. A classic tool script deliberately kept parsing pending for 3 seconds. Timings are measured from navigation; they record the first drawn canvas observed by the test, not a live-LMS performance guarantee.

| Event | v1.1.0 | v1.1.1 |
|---|---:|---:|
| Stars drawn | 3695.7 ms | 328.8 ms |
| First folded-field frame drawn | 3695.7 ms | 328.8 ms |
| Full renderer first draw | 3695.7 ms | 855.1 ms |
| DOMContentLoaded | 3167.0 ms | 3123.5 ms |

The new first frame arrived alongside the workspace, while Sakai was still parsing. Reduced-motion startup also drew the stars and first field at 70.8 ms in its separate run. Hardware, driver startup and actual server markup can change these values.

- 36/36 existing main browser regressions passed, including all eight viewport widths, star proximity glow, native forms and PDF navigation.
- 5/5 WebGL-disabled/cancellation checks passed.
- 7/7 unit/security checks passed.

Raw startup timing and early screenshots are in `reports/startup-v1.1.0/` and `reports/startup-v1.1.1/`. Run `npm run test:startup` to repeat the new check. Normal tests use this suite as well.

These checks used intercepted synthetic Sakai responses, without accessing a university account. Authenticated live LUMS and native hidden-tab behavior remain unverified, as documented in the earlier release report. No publication or real academic submission occurred.
