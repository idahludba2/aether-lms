# Aether LMS v1.2.1 — immediate hover-preview dismissal

Continues the existing extension on `feature/v1.2.1`. v1.2.0, earlier releases and the original v0.8.1 baseline remain preserved. Upgrade by copying all release files into the existing unpacked extension folder, choosing Reload in chrome://extensions and refreshing LMS tabs. No new permissions or settings migration are needed.

## Fix

The old preview used a 260 ms closing timer. Entering another resource cancelled that timer before the next 320 ms hover-open timer fired, leaving the old panel visible after its source had been left.

Hover previews now dismiss synchronously in the pointer-leave event when the pointer is outside both their source resource and panel. Switching resources removes the old panel immediately, then retains the existing opening delay for the new resource. Leaving early cancels pending opening, and dismissing during loading aborts the read. Late responses cannot recreate a dismissed preview.

Portal and embedded-tool pointer movement, viewport exits and scrolling are covered. A direct move into the preview keeps it usable; leaving the panel dismisses it immediately. The removal does not wait for an animation or a closing timer. Clicking Preview or interacting with its keyboard controls keeps an explicit reader stable until closing or moving focus to a known outside control. Cross-origin PDF focus transitions with a null destination are handled without prematurely closing the reader. Escape still closes and restores focus.

Native resource links and actions, preview limits, permissions, Gradebook/Roster styling, page-wide stars and fast visual startup are retained.

Eight new real-pointer regressions cover immediate resource exit, movement between resources, cancellation before opening, moving into and out of the panel, the PDF iframe and viewport exit, embedded-resource exit, aborting a pending read, scrolling, and explicit/keyboard readers. The leave tests inspect the DOM in a microtask at the end of the pointer-leave dispatch, so a delayed timer cannot pass due to test-runner latency. The first new regression failed against v1.2.0 as expected; that reproduction is retained in `reports/hover-before-v1.2.1/results.json`.

Existing checks cover resource previews and native handlers, both PDF pages and keyboard navigation, assignment forms, OFF restoration, graphics fallbacks, origin isolation, Gradebook/Roster controls and eight responsive widths. Startup and fallback checks also remain passing. The final ZIP and unpacked release are compared against all 234 normalized source assets; hashes are recorded in `release-v1.2.1-sha256.json` and `reports/package-integrity-v1.2.1.json`.

Authenticated live LUMS compatibility remains unverified. Native hidden-tab behavior remains the previously documented automation-host limitation and is not counted as a passing check.
